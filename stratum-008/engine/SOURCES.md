# Offline casting sources

The web build loads the shipped Jianyi WebAssembly module from its own assets. The Apple host calls the Jianyi C ABI through a Swift module and the matching arm64 iPhone and simulator archives. Both send only the timestamp to the engine. The binary artifacts, binding and engine result types are from the isolated Zhouyi Exact implementation. The `jianyi-wasm` package declares MIT or Apache-2.0 licensing. [Zhouyi source snapshot](https://github.com/studiozojer/zhouyi/tree/01eb63b30ed0ca05d5d5052a1b5e218648abc8c9/zhouyi-exact) · [Jianyi source](https://github.com/studiozojer/jianyi)

The local English lens is the studio’s unrestricted English translation of Richard Wilhelm’s *I Ging: Das Buch der Wandlungen* (1924). The original pack identifies the 2026 translation as machine-assisted and unreviewed; that attribution travels with each reading. Judgment, image, line passages and any commentary come from that one pack. Its second hexagram omits the Image; the reading preserves that absence. The compact figure catalog retains Zhouyi's number, names and binary pattern. The glyph is derived from the King Wen number.
